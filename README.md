# Edge AI Inference Engine

Optimized AI inference for resource-constrained IoT devices.

## Optimizations
- INT8 Quantization: 4x model compression
- Structured pruning
- Knowledge Distillation
- Mobile-optimized architectures (MobileNetV3, EfficientNet-Lite)

## Target Platforms
| Platform | RAM | Speed |
|----------|-----|-------|
| Raspberry Pi 4 | 4GB | 45ms |
| Coral Edge TPU | 8MB | 2ms |
| Jetson Nano | 4GB | 8ms |
